Course intro and project roadmap

This page introduces the WAPH course and shows the hands-on work that leads into the first individual project. I kept the layout consistent with the homepage so the site feels like one connected portfolio instead of separate fragments.

Instructor Dr. Phu Phung University of Cincinnati

What the course covers

Front-end fundamentals, Ajax, JavaScript interactions, browser cookies, and GitHub Pages deployment.

Why it matters

The work builds the skills needed for secure, responsive, and API-driven web applications.

My takeaway

I learned how small client-side features can make a profile site feel active, personal, and professional.

Hands-on roadmap

From foundation work to the individual project

Labs 0 to 2

Core HTML structure, CSS presentation, JavaScript basics, jQuery, and Ajax-based data fetching.

Individual Project 1

A polished GitHub Pages profile site with clocks, cookies, public APIs, and a course intro page.

Later work

Secure web development, session handling, and more advanced project work after this milestone.
