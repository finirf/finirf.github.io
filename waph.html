Web Application Programming and Hacking

Course intro and project roadmap

Web Application Programming and Hacking (WAPH), taught by Dr. Phu Phung, bridges the gap between full-stack web engineering and software security. The course emphasizes building robust web applications while also auditing them for common vulnerabilities such as Cross-Site Scripting.

Instructor Dr. Phu Phung University of Cincinnati
Core Concepts & Technologies Learned

Technical pillars covered so far

The Evolution of the Web Architecture

  • Web 1.0: Static, read-only pages built from flat plaintext and HTML.
  • Web 2.0: Interactive, read-write web applications powered by databases and user-generated content.
  • Web 3.0: A read-write-trust model focused on decentralized and verifiable data.

Protocol and Backend Engineering

  • HTTP: A stateless and synchronous protocol that shapes session tracking and attack surfaces.
  • CGI: Low-level gateway programming with C applications running behind Apache.
  • PHP: Server-side scripting for dynamic request handling using globals such as $_REQUEST.

Front-End Foundations & Libraries

  • HTML and CSS: Native document structure, forms, and responsive presentation.
  • JavaScript: Client-side validation, DOM updates, cookies, and asynchronous requests.
  • jQuery and utilities: Lightweight library support for DOM manipulation and interactivity.

Defensive Security Engineering

  • GET vs POST: Comparing URL-exposed parameters with request-body submission.
  • Input sanitization: Identifying vulnerable entry points before data reaches sensitive logic.
  • Output encoding: Neutralizing Cross-Site Scripting by preserving context and blocking script execution.
